TS VISUALS WEBSITE

FILES
- index.html       = Home page
- portfolio.html   = Portfolio page
- about.html       = About page
- book.html        = Booking page
- style.css        = Entire website design/layout
- script.js        = EASY EDIT AREA
- images/          = Put your photos here

EASY EDITING
Open script.js.

1. Change:
SITE.email = "YOUR-EMAIL@example.com"

2. Socials are already set as:
Instagram: ts.visuals1
TikTok: tsvisuals.uk

3. Change portfolio information in SITE.portfolio.

Each portfolio item looks like:
{
  image: "images/photo1.jpg",
  title: "Summer Shoot",
  category: "Portraits",
  status: "available"
}

Status options:
- available
- booked
- coming-soon
- private

ADDING A PHOTO
1. Put the photo into the images folder.
2. Name it photo7.jpg (or another name).
3. Add a new portfolio item to script.js.

HERO IMAGE
Put your main homepage image in images/ and name it:
hero.jpg

ABOUT PHOTO
The About page currently has a placeholder. You can replace the placeholder with an image later.

BOOKING
The booking form uses mailto, so it does not require a paid form service. The visitor's normal email app opens with the enquiry prepared.

IMPORTANT
If you want a true online booking calendar where visitors choose available dates/times and you receive bookings automatically, that needs a separate booking service/backend. This starter site does not charge for the website itself.
